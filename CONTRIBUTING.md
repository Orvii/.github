# Contributing to Orvii

Orvii is a two-person collective. Everything public lives in this organization; everything here explains how to add to it.

## The research set

Seven repos, one method: measure, cite, publish, correct.

| Repo | Takes contributions of |
|---|---|
| [harness-atlas](https://github.com/Orvii/harness-atlas) | new/refreshed harness rows (see its CONTRIBUTING: evidence contract) |
| [convention-map](https://github.com/Orvii/convention-map) | convention-file findings with fetched doc URLs |
| [bench-notes](https://github.com/Orvii/bench-notes) | notes in the house shape: claim / why / failure example / rule / counter-note |
| [equivalence-notes](https://github.com/Orvii/equivalence-notes) | same shape, equivalence-testing problems |
| [provider-reliability](https://github.com/Orvii/provider-reliability) | method notes, schema improvements, probes — never raw traffic |
| [retractions](https://github.com/Orvii/retractions) | entries for beliefs we published and killed (template in its CONTRIBUTING) |
| [svg-instruments](https://github.com/Orvii/svg-instruments) | sanitizer-safe patterns with failure-mode READMEs |

## Ground rules

1. **Evidence over memory.** Claims about tools cite a URL fetched in the same run; claims about numbers carry machine, runtime, profile, date.
2. **Corrections are contributions.** A retraction entry or an atlas cell fix is as welcome as a new page — arguably more.
3. **No raw traffic, no rankings, no personal data.** See provider-reliability's CONTRIBUTING for the line.
4. **English** in all public artifacts; the house style is plain sentences over adjectives.
5. Small PRs. One belief, one note, one harness row. Reviewable beats comprehensive.

## How to start

Open an issue on the target repo describing the finding and its evidence before writing prose — half of all proposed notes die there, cheaply. If it survives the issue, the PR is usually one file.
